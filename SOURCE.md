# Source and Originality

`moonbit-energybalance` is authored from scratch in this repository for the
MoonBit August hackathon track. It is not a direct port of an existing library.

The formulas implemented here are standard steady-state process engineering
relations: sensible enthalpy from heat-capacity integration, latent-heat
crossing terms, inlet/outlet enthalpy-flow balances, LMTD, UA, and simple
utility flow estimates. Names, file layout, tests, and documentation were
written specifically for this project.

Before implementation, Mooncakes was checked with keywords including `energy
balance`, `enthalpy`, `heat exchanger`, `thermodynamics`, `utility`, and related
Chinese terms. No mature MoonBit package with highly overlapping process
energy-balance functionality was found.

The repository uses the Apache-2.0 license generated by `moon new`, with the
account owner as the sole contributor.
